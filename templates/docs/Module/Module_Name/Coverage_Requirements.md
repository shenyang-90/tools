# 验证覆盖率要求规范

> 基于 workflow/SOC_DESIGN_WORKFLOW.md 定义
> 适用于 IDR 阶段 Code Freeze 门禁

---

## 覆盖率目标汇总

| 覆盖率类型 | 目标值 | 关键模块要求 | 验收状态 |
|-----------|--------|-------------|---------|
| **代码覆盖率 (Code Coverage)** | > 90% | > 95% | ☐ |
| **功能覆盖率 (Functional Coverage)** | > 85% | > 90% | ☐ |
| **断言覆盖率 (Assertion Coverage)** | > 95% | 100% | ☐ |
| **FSM覆盖率 (FSM Coverage)** | > 95% | 100% | ☐ |
| **Toggle覆盖率** | > 90% | > 95% | ☐ |

---

## 代码覆盖率 (Code Coverage) - > 90%

### 覆盖类型要求

| 覆盖类型 | 目标 | 说明 |
|---------|------|------|
| Line Coverage | > 90% | 代码行覆盖 |
| Statement Coverage | > 90% | 语句覆盖 |
| Branch Coverage | > 90% | 分支覆盖 |
| Expression Coverage | > 85% | 表达式覆盖 |
| Condition Coverage | > 85% | 条件覆盖 |

### 豁免情况
以下情况可申请豁免，需记录原因：
- [ ] Debug/诊断代码
- [ ] 错误处理路径（不可触发）
- [ ] 保留/未来功能
- [ ] 第三方IP内部

---

## 功能覆盖率 (Functional Coverage) - > 85%

### 覆盖点分类

| 类别 | 目标 | 示例 |
|------|------|------|
| 寄存器配置 | 100% | 所有寄存器位域组合 |
| 操作模式 | > 90% | 所有工作模式 |
| 数据通路 | > 85% | 所有数据路径 |
| 边界条件 | > 95% | 最小/最大值，边界值 |
| 错误注入 | 100% | 所有错误处理场景 |

### Covergroup 要求
- 每个主要功能一个 Covergroup
- Cross coverage 定义完整
- bins 划分合理（不过多/过少）

---

## 断言覆盖率 (Assertion Coverage) - > 95%

### 断言分类

| 类型 | 要求 | 说明 |
|------|------|------|
| 协议断言 | 100% | 接口协议检查 |
| 安全断言 | 100% | 功能安全相关 |
| 时序断言 | > 95% | 时序约束检查 |
| 数据完整性 | 100% | 数据一致性检查 |

### SVA 覆盖检查点
- [ ] 所有SVA被触发过
- [ ] 无永久失败的断言
- [ ] 断言密度合理（关键路径每10-20行一个）

---

## FSM覆盖率 (FSM Coverage) - > 95%

### 覆盖要求

| 检查项 | 目标 | 说明 |
|--------|------|------|
| 状态覆盖 | 100% | 所有状态至少访问一次 |
| 转换覆盖 | > 95% | 所有有效状态转换 |
| 路径覆盖 | > 85% | 关键状态序列 |

### 特殊要求
- 复位状态必须验证
- 非法状态转换检查
- 状态机死锁检查

---

## Toggle覆盖率 - > 90%

### 信号分类要求

| 信号类型 | 目标 | 说明 |
|---------|------|------|
| 控制信号 | 100% | 0→1 和 1→0 都触发 |
| 数据总线 | > 90% | 所有bit都有翻转 |
| 状态信号 | 100% | 所有状态值 |
| 时钟/复位 | 100% | 基础信号 |

## 覆盖率收敛计划

```
Month 1-2: 基础覆盖
├── Line/Statement > 70%
├── 基础功能覆盖 > 60%
└── 关键断言覆盖 > 80%

Month 3-4: 深度覆盖
├── Line/Statement > 85%
├── 功能覆盖 > 75%
├── 边界条件覆盖 > 80%
└── FSM覆盖 > 90%

Month 5-6: 最终收敛
├── 代码覆盖 > 90% (关键>95%)
├── 功能覆盖 > 85% (关键>90%)
├── 断言覆盖 > 95%
├── FSM覆盖 > 95%
└── 覆盖率报告归档
```

## 覆盖率报告模板

### 报告命名
```
Coverage_Report_[Module]_[Date].md

例如:
- Coverage_Report_CPU_20260327.md
- Coverage_Report_DMA_20260327.md
```

### 报告内容
1. 覆盖率汇总表
2. 各类型覆盖率详情
3. 未覆盖代码分析
4. 豁免项列表
5. 改进计划
6. 签字确认

## 工具配置

### VCS 覆盖率选项
```bash
# 编译选项
vcs -cm line+cond+fsm+tgl+assert ...

# 仿真选项
simv -cm line+cond+fsm+tgl+assert ...
```

### Verilator 覆盖率
```bash
verilator --coverage --coverage-line --coverage-toggle ...
```

### 合并报告
```bash
# VCS urg
urg -dir simv.vdb ...
```
